sTrack - simply handle IT Track  version 2.1  (Windows)

1. Unzip this file (right-click > Extract All). Don't run it from inside the zip.
2. Put sTrack.exe in a folder you can write to (e.g. Documents\sTrack), then double-click it.
3. If Windows shows "Windows protected your PC": click "More info" > "Run anyway".
   (The app isn't code-signed yet.)

Working as a team
- Click the database button at the top right > type a shared path, for example
  \\fileserver\PM\ProjectA.strack.json > "Create a new database here".
- Click "Copy share text" and send it to the team. They paste the same path and click "Connect".
- Everyone needs read/write access to that folder.

Files
- Ctrl+S saves a copy (.strack.json). The folder button opens files and imports/exports Excel or CSV.
- Capture (Ctrl+E) copies the chart to the clipboard; Ctrl+Shift+S snips an area.
- Your own copy of the plan is kept in %LOCALAPPDATA%\sTrack.

Nothing is uploaded - the app works fully offline.
Needs Microsoft Edge WebView2 Runtime - already built into Windows 10/11.
Press F1 inside the app for help.
