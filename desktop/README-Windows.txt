sGantt - smart Gantt  version 1.0  (Windows)

1. Unzip this file (right-click > Extract All). Don't run it from inside the zip.
2. Put sGantt.exe in a folder you can write to (e.g. Documents\sGantt), then double-click it.
3. If Windows shows "Windows protected your PC": click "More info" > "Run anyway".
   (The app isn't code-signed yet.)

Saving
- Save (Ctrl+S) writes an editable .sgantt.json file where you choose. Open with Ctrl+O.
- Export PNG (Ctrl+E) saves a picture of the chart.
- Your current plan is also autosaved in %LOCALAPPDATA%\sGantt.

Nothing is uploaded - the app works fully offline.
Needs Microsoft Edge WebView2 Runtime - already built into Windows 10/11.
Click ? in the toolbar for help and shortcuts.
